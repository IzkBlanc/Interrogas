# Interrogas

> Um quiz leve, divertido e direto ao ponto — feito para te ajudar a memorizar o que importa dentro do jogo.


## ✨ Sobre o projeto

**Interrogas** é um projeto em construção que traz um quiz sobre o jogo League of Legends. Uma maneira orgânica de gravar informações importante pra quem joga. A motivação é aprender o que não sei e ensinar o que estudo.
Mirando sempre na simpliscidade. 

## 🔍 Funcionalidades

- Exibe perguntas específicas sobre campeões;
- Mostra se sua resposta está certa ou errada.
- Visual limpo e focado na experiência do usuário.
- ⚠️ No momento, apenas a campeã **Ahri** está disponível.

## 🔧 Tecnologias utilizadas

Projeto desenvolvido com:

- HTML5
- CSS3
- JavaScript puro (Vanilla JS)
